# Where is Jovi? — Interactive Preposition & Following Directions SLP Scene 🧭🐕‍🦺🐷

An interactive, single-file Speech-Language Pathology (SLP) web application starring **Jovi** (15-lb black Scottish Terrier), **Piggy** (her pink stuffed pig), and **Snoop** (her older brother dog).

## ✨ What's Inside
- **4 Interactive Scenes from Jovi's World**: Field Club Backyard & Deck, Hickory Street Living Room, Jovi's Chef Kitchen, and Shaila's Speech Therapy Room.
- **8 Movable Characters & Objects**: Jovi, Piggy, Snoop, Squeaky Ball, Mismatched Socks, Homemade Dinner Bowl, Crunchy Bone, and Backyard Squirrel.
- **9 Spatial Preposition Zones per Scene**: `ON`, `UNDER`, `IN`, `NEXT TO`, `BEHIND`, `IN FRONT OF`, `BETWEEN`, and `ABOVE`.
- **3 Clinical Play Modes**:
  1. **🎯 Follow Directions**: 1-Step, 2-Step (`First/Then`), and Temporal (`Before/After`) directions with automatic verification.
  2. **🕵️ Hide & Seek Piggy**: Expressive mystery game targeting *Where* questions and prepositional phrases.
  3. **🎨 Free Barrier Scene**: Open-ended placement for peer barrier games and expanding utterances.
- **📋 Built-In SLP Instructor Preparation Guide**: Complete session blueprint and K–5 differentiation guide.
- **💬 Multimodal Spatial & Core AAC Strip**: 14 color-coded tiles with Web Speech API voice output.
- **📊 SLP Session Data & SOAP Note Generator**: Tracks Independent, Cued, and Modeled trials and exports a copy-pasteable progress note.

## 🚀 How to Run on Shaila's Computer or GitHub Pages
- **Run Offline on Any Computer**: Double-click `where-is-jovi.html` (or `index.html` inside the zip) to open directly in Chrome, Edge, or Safari.
- **Host on GitHub Pages**: Upload the contents of `where-is-jovi-slp-repo.zip` to a new GitHub repository and enable **Settings → Pages → Deploy from main branch**.
